# MAX Bot Service

Микросервис для интеграции с мессенджером MAX. Позволяет клиентам взаимодействовать с юридическим ИИ-ассистентом напрямую через платформу MAX.

## 🛠 Технологии
- **Библиотека**: `maxapi` (aiogram-style SDK для MAX).
- **Связь**: `aiohttp` для запросов к `intake-service`.
- **Логирование**: Стандартизированный логгер с выводом в stdout.

## 📋 Функционал
- Приветствие новых пользователей через событие `BotStarted`.
- Интерактивный сбор юридической информации (диалог с ИИ).
- Использование Inline-кнопок (Callback Buttons) для подтверждения отправки заявки.
- Автоматическая маркировка всех сообщений и дел тегом `source: max`.

## ⚙️ Настройка
Сервис настраивается через переменные окружения (обычно в `backend/.env`):

| Переменная | Описание |
|------------|----------|
| `MAX_BOT_TOKEN` | Токен бота, полученный в панели разработчика MAX. |
| `API_URL` | URL сервиса `intake-agent` (по умолчанию `http://intake-agent:8001`). |

## 🚀 Разработка (Локальный запуск)
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите бота:
   ```bash
   python main.py
   ```

## 🏗 Архитектура кода
- `main.py`: Точка входа, регистрация хендлеров для сообщений и коллбэков.
- `core/logger.py`: Настройка форматирования логов.
- `Dockerfile`: Образ на базе `python:3.11-slim` для развертывания в Docker.
